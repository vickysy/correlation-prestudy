# 相关性预习 · correlation-prestudy

> 把"预习"从"提前学课本"变成"悄悄播种先验知识"。

一个 AI Skill：给小学 3–6 年级（语文人教版 / 数学北师大版）生成"相关性预习"材料——开课前，让孩子通过好玩的故事、真实的数学史 / 字源、生活联结，先对要学的单元产生熟悉与好奇；等课上真正讲到时，体验到"哇，这个我讨论过 / 我见过"（鸡尾酒效应）。不抢老师的工作，只做家庭"边角料"。

## 它做什么

- **每单元一张可交互预习卡**：好奇钩子 → 背后故事 → 想一想 → 生活联结 → 上课任务 → 想深入·资源库
- **孩子的自学工作台（HTML）**：我的星系 / 知识宇宙 / 大脑工具箱 / 我的档案 / AI 协作者 / 我的作品；可打印、多主题、无科目标签
- **平台三板块**：教育方法集合 / 带着语文课本去看世界 / 数学书背后的数学史和数学家的故事

## 核心原则（硬约束）

1. **相关性预习 ≠ 提前学**：只播种兴趣、背景、联结，不做超纲、不提前上课
2. **真实有分量，不低幼**：用真实数学史、字源、人物与事件，拒绝"拟人化睡前故事"包装
3. **悄悄进行**：孩子视角是"我平时看的书 / 讨论过的东西在课本里出现了"
4. **跨学科组织，不标科目**：孩子界面不出现"语文""数学"标签，只看到一串好玩的问题 / 主题
5. **孩子口吻**：面向孩子的文案用"你"直接对话，不用家长腔
6. **不用积分 / 被动奖励**：一切以好奇心驱动，成就感来自内在反馈

## 怎么用

把整个文件夹放进你的 AI 助手（小龙虾 OpenClaw / Claude Code / Codex 等）的 skills 目录，然后说：

> 给四年级生成语文（人教版）的相关性预习材料

或

> 帮我做一个孩子的自学工作台
