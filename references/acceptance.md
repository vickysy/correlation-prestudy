# 验收清单（生成后逐项自查）

## 内容
- [ ] 输入年级 + 教材版本 + 学期后，能生成完整单元/课文清单（不漏、不编造篇目）
- [ ] 每单元/课文六幕齐全：好奇钩子 → 背后故事 → 想一想 → 生活联结 → 上课任务 → 想深入·资源库
- [ ] 背后故事真实可溯源（数学史/字源/人物/事件，标注来源）
- [ ] 不低幼、不拟人化包装（用户明确否决过"睡前故事"式）
- [ ] 明显是"预习播种"，不是"提前上课"（不做超纲教学）
- [ ] 给家长的补充块单独标注，不与孩子视角混淆

## 资源库
- [ ] 纪录片/动画/文章可点开（链接真实）；书有购买入口（当当/豆瓣等）
- [ ] 资源真实存在，无编造作品
- [ ] 动手实验给出可操作步骤

## 文案
- [ ] 面向孩子用"你"直接对话，无家长腔（不出现"爸妈买一本""睡前读一段"等）
- [ ] 好奇钩子是一个真问题（孩子会想问"为什么"）

## 交付
- [ ] HTML 探险页可交互（选择即时反馈）、可打印；或按约定交付飞书文档/Markdown
- [ ] 资源链接可访问性已核对
