# 教育方法 / 学习科学集合（平台板块①"和孩子一起更好的学习"）

这一板块是"相关性预习"整套方法背后的理论底座。面向家长呈现时，每条都要落到"所以我可以怎么做"，不是堆术语。

## 1. 鸡尾酒效应（选择性注意 · 自我参照）

- 现象：嘈杂环境里有人喊你名字，你立刻听见；别人说的话你没注意。
- 机制：大脑对"和自己有关"的信息有优先加工通道（自我参照效应），相关信息记得更牢。
- 落到预习：提前让孩子对"大数""编码""角"这些词产生熟悉与记忆，上课时这些概念就像"喊他的名字"，一出现就被听见。
- 家长操作：预习 = 先把"名字"种进孩子心里。

## 2. 先验知识 / 图式（脑科学）

- 原理：人是带着先验知识学习的——在已知上盖楼，而非一步踏入未知。能学会多少，取决于已有多少先验知识。
- 落到预习：预习不是"提前学会"，而是提前铺好"挂钩"（图式），课上新知识一到就有地方挂。
- 用户原话可引用："人的学习是递归的——知识一层层嵌套，每层都长在上一层。"

## 3. 好奇心回路 / 多巴胺

- 机制："想知道答案"的预期本身激活奖赏回路；好问题让人进入"忘我"状态。
- 落到预习：每个单元用一个大问题开场（为什么一圈是 360°？没有 0 怎么写大数？），把"要学的"变成"想知道的"。
- 好问题比好答案重要：会提问的孩子，自己会进入主动探索。

## 4. 自我决定理论（SDT）

- 三种基本心理需求：自主、胜任、联结。被满足时内在动机点燃。
- 预习提供"联结感"（这个和我有关）；不做超前教学，保护"自主"（我是在玩，不是在补课）。
- 反面：管得越多，孩子越没自驱力。

## 5. 建构主义（杜威 / 皮亚杰 / 维果茨基）

- 知识是学习者基于已有经验主动建构的；熟悉情境是脚手架，让新知"挂"得住。
- 最近的经历（去过钱塘江、看过的纪录片、读过的数学书）就是最好的课堂入口。

## 6. "边角料"定位（家长分工观）

- 家长不与老师抢工作：老师负责教、练、考；家长负责兴趣、背景、联结、资源。
- 时间观：每学期开头花少量时间（约一小时）梳理全局，平时放手；找到"最重要值得花的时间"，其余不管更好。
- 目标：孩子在校内解决"会做"；家长解决"觉得有意思、有联结"。

## 7. 兴趣三步法（数学为例）

1. **纪录片**：看数学家和知名定理的故事，产生对"人"和"问题"的兴趣；
2. **数学书**：兴趣起来后读数学童话/科普（如李毓佩），故事里带知识；
3. **解题乐趣**：在家偶尔出好玩的题，孩子会主动要"思维题"。

## 8. 热点与宏大图景

- 用真实现象/悬念（如菲尔兹奖、未被证明的猜想）让孩子知道"世界上还有很多有趣的问题没被解决"，数学不只是计算题。
- 公式/概念的词源词根追根溯源，会带来"恍然大悟"。
