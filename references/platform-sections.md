# 平台三板块生成规范

"相关性预习平台"由三大板块组成。本文件定义每板块的生成规范。

## 板块① 和孩子一起更好的学习

- **定位**：给家长看的教育方法/学习科学集合（本次方法的理论底座）。
- **内容来源**：`methodology.md` 的每一条（鸡尾酒效应、先验知识、好奇心回路、SDT、建构主义、边角料定位、兴趣三步、热点图景）。
- **呈现**：每条"一句话原理 + 家长立刻能做的动作 + 可讲给孩子的小例子"；可用 HTML 卡片或飞书文档。
- **触发**：用户想看方法/理论/为什么这样做时生成。

## 板块② 带着语文课本去看世界

- **定位**：把每一篇语文课文接上真实世界——地方、自然、工程、历史、人物、字源。
- **生成方式**：逐篇课文做"联结卡"：
  1. 这篇课文讲了什么（一句话）；
  2. 世界联结：真实存在的地点/现象/工程/人物（如观潮→钱塘江大潮、茅以升大桥；田忌赛马→《史记·孙子吴起列传》、博弈论）；
  3. 可以去看/去读/去查的真实资源（纪录片、书、官方科普、地图）；
  4. "如果能出门"：带孩子去哪个真实地点、看什么。
- **示例**：
  - 《观潮》→ 钱塘江大潮（农历八月十八、引潮力、喇叭形河口）+ 茅以升钱塘江大桥 + 央视《钱江潮》《涌潮之上》+ 海宁盐官观潮
  - 《田忌赛马》→ 《史记·孙子吴起列传》（孙膑）+ 对策论/最优策略 + 《少年读史记》
  - 《走月亮》→ 月光下的行走与观察，字源"明""月"等
- **注意**：语文课文篇目按人教版对应年级核对，不编造。

## 板块③ 数学书背后的数学史和数学家的故事

- **定位**：每个数学单元 → 对应的真实数学史 + 数学家 + 背后故事。
- **生成方式**：逐单元做"历史卡"：
  1. 本单元知识点一句话；
  2. 数学史故事（真实、有分量、可溯源，来源如《这才是好读的数学史》、伽莫夫《从一到无穷大》、BBC《数学的故事》）；
  3. 相关数学家/文明（人名 + 时代 + 贡献）；
  4. "想深入"资源（纪录片/书/绘本/动画/动手）。
- **示例**：
  - 认识更大的数 → "0"的诞生、十进制与各文明计数（古罗马无 0、古巴比伦 60 进制）、阿基米德《数沙者》
  - 线与角 → 欧几里得《几何原本》、为什么一圈 360°（六十进制）、量角器的由来
  - 编码 → 莱布尼茨二进制、布尔代数、信息论（香农）
  - 运算律 → 代数符号的历史（韦达、笛卡尔）、哈代"证明对显然之事的尊重"
  - 数图形 → 欧拉与哥尼斯堡七桥（图论起源）
  - 数据表示 → 统计学起源（格雷特 1662 年首次发表人口统计）
- **注意**：数学史事实要可溯源；不低幼化；与本学期北师大版单元一一对应。
